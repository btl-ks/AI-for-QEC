# Spec Delta

## Purpose

定义实验中多条随机流之间的独立性与可重建性，使同一主种子下的数据生成、模型初始化、训练与评估各自取得互不干扰的随机序列，并使任一条流都能从记录的身份精确重建。

## ADDED Requirements

### Requirement: 具名随机流相互独立且可确定性重建
系统 SHALL 为每条具名随机流从实验主种子派生独立的初始状态。相同主种子与相同流名 MUST 重建相同的序列；同一主种子下不同流名 MUST NOT 共享初始状态，且任一条流的取值 MUST NOT 依赖另一条流被消费的次数或顺序。

#### Scenario: 同一主种子下的两条不同具名流
- **WHEN** 实验在同一主种子下使用两条名称不同的随机流
- **THEN** 两条流的初始状态不同，且各自的取值不随另一条流的消费而改变

#### Scenario: 重复重建同一具名流
- **WHEN** 同一主种子与同一流名在两次执行中被重建
- **THEN** 两次产生相同的序列

#### Scenario: 主种子改变
- **WHEN** 实验主种子改变而流名不变
- **THEN** 每条具名流的初始状态随之改变

#### Scenario: 新增一条具名流
- **WHEN** 实验引入一条此前不存在的具名随机流
- **THEN** 该流与所有既有流的初始状态不同，且引入它不改变任何既有流的序列
