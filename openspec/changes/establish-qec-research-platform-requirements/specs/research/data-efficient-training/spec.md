# Spec Delta

## Purpose

定义稀有逻辑错误场景中的数据高效训练实验，使困难样本挖掘、课程学习和自适应采样能够在固定预算、无测试泄漏且偏差受控的条件下验证。

## ADDED Requirements

### Requirement: 样本效率实验使用预登记预算
系统 SHALL 在正式运行前冻结候选生成量、实际训练样本量、训练步数或计算时间中的主要预算，并规定目标指标与停止规则。

#### Scenario: 比较自适应采样与均匀采样
- **WHEN** 两种训练策略进入正式比较
- **THEN** 它们使用同一模型族、初始化协议、测试集和预登记的主要预算，差异仅限声明的采样策略

### Requirement: 困难样本选择可审计
系统 SHALL 为每个候选样本记录足以重建选择决策的评分器版本、分数、选择概率、来源桶和进入训练缓冲区的原因。

#### Scenario: 使用模型置信度选择样本
- **WHEN** 候选样本因低置信度进入困难样本缓冲区
- **THEN** run 保存评分所用 checkpoint 身份、阈值和选择统计

#### Scenario: 使用 RBM 能量选择样本
- **WHEN** RBM 能量被用作困难度评分
- **THEN** RBM 作为可替换评分器单独评估，并通过消融区分其贡献与缓冲区本身的贡献

### Requirement: 自适应采样控制训练偏差
系统 SHALL 明确困难样本与原分布样本的混合规则，并在需要时使用选择概率或权重修正；系统 MUST 保留原分布上的独立评估。

#### Scenario: 困难样本被过采样
- **WHEN** 训练批次中的困难样本比例高于其自然发生比例
- **THEN** 系统记录实际采样分布、修正方法和未修正对照

### Requirement: 课程调度具有明确状态
系统 SHALL 把码距、物理错误率、轮数和噪声域的课程选择视为可恢复的训练状态，并记录每次调度决策。

#### Scenario: 训练从较小码距扩展
- **WHEN** 调度器从较小码距转向较大码距
- **THEN** run 记录触发条件、各域已消费样本数和恢复所需的调度器状态

### Requirement: 报告稀有事件与样本效率
系统 SHALL 报告每个域中的逻辑失败样本数、自然发生率、训练样本数、候选生成量、训练时间和达到预登记目标所需成本。

#### Scenario: 逻辑失败样本不足
- **WHEN** 某个评估单元未达到预登记的最小 failure budget
- **THEN** 系统继续采样至上限或将结论标记为证据不足，不得仅报告不稳定点估计

### Requirement: 验证跨域泛化
正式结果 SHALL 在未参与采样器更新的噪声参数、码距、轮数或相关噪声域上评估，并使用多个独立 seed 和置信区间。

#### Scenario: 方法只改善训练域
- **WHEN** 自适应采样降低训练域误差但未改善预登记的独立测试域
- **THEN** 报告将结果限定为训练域收益，不得声称获得通用泛化
